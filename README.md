
# ANJALI PYTHON LAB

A collection of Python programs completed as part of my programming lab work at Jain University.

This repository is organized by unit so that concepts, exercises, and experiments are easy to find. Each folder contains standalone programs, along with small examples for practicing Python fundamentals.

---

## What This Repository Covers

The programs in this repository cover the basic concepts of Python programming, including:

- Variables and Data Types
- User Input and Output
- Arithmetic Operations
- Conditional Statements
- Loops
- Functions
- Strings
- Lists
- Tuples
- Dictionaries
- File Handling
- Exception Handling
- Other lab exercises as they're assigned

## Repository Structure

Programs are grouped into unit folders. File names correspond to the program or exercise number.
